How I Built It

เว็บไซต์นี้พัฒนาตามขั้นตอนดังนี้

  1. วางโครงสร้าง HTML เริ่มจากสร้างโครงสร้างพื้นฐาน (<!DOCTYPE html>, <html>, <head>, <body>)
    พร้อมตั้งค่า <meta charset="UTF-8"> และ <meta name="viewport">
    เพื่อรองรับภาษาไทยและการแสดงผลบนมือถือ

  2. เพิ่มเนื้อหาและองค์ประกอบ ใส่ข้อความ รูปภาพ ลิงก์ และรายการ (list) ให้เหมาะสมกับแต่ละหัวข้อ

  3. จัดรูปแบบด้วย CSS เชื่อมไฟล์ CSS ภายนอกเข้ากับ HTML ผ่าน <link rel="stylesheet"> แล้วกำหนดสี ฟอนต์ ระยะห่าง (margin/padding) และจัด layout ให้อ่านง่าย

  4. ทดสอบและแก้ไขข้อผิดพลาด เปิดเว็บไซต์ผ่านเบราว์เซอร์ ตรวจสอบการแสดงผล และใช้ DevTools (Inspect) เพื่อหาสาเหตุของปัญหา layout เช่น ระยะขอบที่ไม่ชิดตามต้องการ

แหล่งข้อมูลอ้างอิง:https://www.w3schools.com/css/

Reflection

ปัญหาที่พบคือการจัดระยะขอบ (margin) ของหน้าเว็บให้ได้ระยะตามที่ต้องการ จึงลองปรับค่าตัวเลขหลาย ๆ แบบ จนได้ค่า px ที่เหมาะสม

จากการทำ A1 นี้ ทำให้เข้าใจการใช้ border และการปรับ padding กับ margin มากขึ้น

หากมีโอกาสได้พัฒนางานนี้ต่อ อยากตกแต่งหน้าเว็บให้สวยงามมากขึ้น โดยนำความรู้ CSS ใหม่ ๆ มาประยุกต์ใช้
